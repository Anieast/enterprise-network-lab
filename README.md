# Enterprise Network Infrastructure Lab

## Overview

This project simulates a multi-site enterprise network
consisting of a headquarters and a branch office.

The network is designed to provide segmentation, centralized
network services, dynamic routing, security controls and
gateway redundancy.

## Objectives

- Design a multi-site enterprise network
- Segment departments using VLANs
- Implement inter-VLAN routing
- Provide centralized DHCP services
- Configure OSPF between sites
- Restrict network access using ACLs
- Implement gateway redundancy using HSRP
- Provide Internet connectivity using NAT
- Simulate and troubleshoot network failures

## Technologies

- Cisco Packet Tracer
- VLAN / IEEE 802.1Q
- Inter-VLAN Routing
- DHCP Relay
- OSPF
- ACL
- HSRP
- NAT
